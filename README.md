# Хорватська A1 → B1 за 36 тижнів

Безкоштовна інтерактивна програма вивчення хорватської мови для україномовних — від рівня A1 до B1. Усе працює в браузері: без реєстрації, без встановлення, без інтернету (крім AI-чату й посилань на хорватські медіа).

**▶ Відкрити онлайн:** https://lvyyln.github.io/croatian-a1-b1/

## Як користуватися

**Варіант 1 — онлайн.** Відкрий посилання вище. Готово.

**Варіант 2 — офлайн на своєму комп'ютері.**
1. Натисни зелену кнопку **Code → Download ZIP** угорі цієї сторінки.
2. Розпакуй архів.
3. Відкрий файл `index.html` подвійним кліком.

Рекомендований браузер — **Microsoft Edge** або **Chrome**. В Edge зазвичай є хорватський голос для озвучення.

## Що всередині

- **3 етапи, 36 тижнів, ~1070 завдань** на кожен день, ~65 хв на день, із прогресом по тижнях.
- **Кнопка «Виконати»** біля кожного завдання — усе робиш тут же:
  - вправи з полями для відповідей і перевіркою (✓ / ✗ / ⚠ діакритика) — понад 3000 пунктів;
  - письмо з автозбереженням і зразками відповідей;
  - запис голосу для говоріння;
  - тексти й діалоги тижня з озвученням.
- **Картки** — інтервальне повторення ~1000 слів програми + твоїх власних.
- **Словник** — додавай свої слова будь-коли.
- **Граматика** — шпаргалка: відмінки, дієслова, енклітики, хибні друзі, відмінності від сербської.
- **AI-чат** — розмовна практика, рольові ігри, перевірка текстів. Потрібен власний ключ API (Claude, OpenAI, Gemini або сумісний сервіс); ключ зберігається лише у твоєму браузері.

## Де зберігаються дані

Прогрес, відповіді, словник і чат зберігаються **лише у твоєму браузері** на цьому пристрої. Нічого не надсилається на сервер.

- Режим інкогніто або очищення даних сайту = прогрес зникне.
- Для резервної копії чи переносу на інший пристрій: **Огляд → Експорт усіх даних**, потім **Імпорт** на іншому пристрої. Голосові записи в копію не входять.

## Застереження

Тексти й вправи створено з допомогою AI та не вичитано носієм мови. Можливі неточності — якщо знайдеш помилку, відкрий Issue.
