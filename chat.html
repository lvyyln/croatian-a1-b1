⚙️ Налаштування AI-провайдера
Ключ API зберігається лише в localStorage цього браузера (на цьому комп'ютері) і нікуди більше не надсилається, крім обраного провайдера. Запити йдуть напряму з браузера до провайдера, без жодного сервера-посередника. Усі витрати за використання API — на твоєму акаунті провайдера. Не користуйся цією сторінкою на чужому комп'ютері.
